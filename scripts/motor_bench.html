Before opening a bus: motor clamped, end effector resting on the scale, power cutoff in reach, fused harness OK, no robot controller running (the bench refuses otherwise). If the robot's motors share this bus, keep them unpowered or make sure the test motor's ID differs. The motor keeps its last command if this server dies: the power cutoff is the real stop.

2 · Rotation control

Enables in operation control with the cap written to the drive and read back. Moves ramp at the set speed. Use it to bring the end effector onto the scale, then Stop.

3 · Maximum torque test (blocked output on the scale)

Torque is commanded with kp 0 (no position loop), so the scale takes the full output. The test stops if the output moves more than the travel guard or turns faster than the speed guard (end effector slipped), on any fault, on the temperature limit, or if this page stops polling.
